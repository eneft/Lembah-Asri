# Character 3D — prototipe uji terpisah

Master desain: user-provided `55CB4398-BC1D-4C5C-BD8C-5974534846DC.jpeg` (gambar acuan terkunci).

**JANGAN** mengganti desain atau scene karakter 2D utama sebelum pengguna menyetujui hasil uji.

- Berkas: `lembah_asri_protagonist_3d.glb` benar-benar berisi mesh 3D.
- Tubuh sekitar 4,5 kepala; pakaian hijau, kaos krem, celana cargo panjang, boots cokelat, rambut berantakan, ransel.
- Rig prototipe: pivot lengan kiri/kanan, kaki kiri/kanan, kepala.
- Gerak Idle/Walk/Run 12 FPS di script Godot; berputar 360 derajat.
- Buka lab lewat tombol **UJI MODEL 3D** dalam scene utama (atau F6). Kembali dari lab via tombol atau Escape/F6.
- Versi tahap pertama masih pakai bentuk 3D sederhana / material polos; **belum** rekonstruksi akurat detail wajah atau tekstur ilustrasi.
- Model dan lab diuji melalui Godot Actions; scene utama tetap `house_garden_stage1.tscn`.
